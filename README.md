# Discovery_app_803A
Proyecto final de la materia de Topicos Selectos de Aplicaciones Web
En nuestra aplicacion logramos realizar una facil accesibilidad a alumnos proximos a egresar de nivel preparatoria la cual nos ayudara a promocionar las distintas ventajas de estudiar en nuestro campus sobre todo en la carrera de ingenieria en sistemas computacionales (ISC) en la cual dicha aplicacion desarrollada nos trae el itinerario, los contactos para mas informes, un codigo QR para acceder a la pagina del instituto para consultar cualquier detalle y un pequeño test para aegurarnos si es la carrera que le gusta a los jovenes alumnos.
